### Changed

- The canvas browser and the Agent browser now share one set of browser controls: Back, Forward, Reload and an address field that shows the site plainly and says "Not secure" for plain http pages. On a narrow panel it shows just the site.
- In the Agent browser, the page now runs edge to edge under those controls.
