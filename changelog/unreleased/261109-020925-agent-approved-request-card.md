### Changed

- **A request another agent approved says so.** Its card reads "Approved by DorkOS PM · Read only", with that agent's picture and the time. It stays in Needs you for a day, then you'll find it in Activity.
- **A request for write access says "Write access needs you."** Agents can only approve Read, so only you can answer it.
- **When an agent asks to approve another agent's request, you see names, not codes.** The card shows which agent asked, with its picture, and which app. The request's code is behind the ⓘ button.
