- A channel you open now starts with its own shared files and a `ROOM.md`, so you no longer need to press **Set up files** first. Rooms you already have are left as they are and keep the button. Direct messages and rooms an agent opens start without files, and nothing changes while room files are switched off in Settings. (FB-39)
