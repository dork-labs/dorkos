### Added

- Every agent picker now shows an agent's own description under its name, where there is one. Two agents can share a name; this is the line that tells them apart by what they do. Agents that have not been given a description simply have no second line.

### Changed

- Starting a direct message when you have no agents yet now offers a **Create agent** button instead of telling you to go and add one.
