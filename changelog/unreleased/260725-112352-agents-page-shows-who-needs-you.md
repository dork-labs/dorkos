### Changed

- The Agents page now leads with the agents that need you. Rows are grouped into **Needs you**, **Working**, and **Quiet**, so the first thing you see is whatever is stuck, not an alphabetical list. Pick a different sort (by name, for example) and the groups flatten.
- Each row now says what the agent last did, in plain words: "Finished a reply", "Got a message", "Cannot be reached". The time it happened, and how many chats are open with it, sit underneath.
- A new **Scheduled** column shows how many scheduled tasks are waiting on each agent. An agent that has gone quiet for a day with tasks still scheduled is flagged as needing you, because those runs are failing.
- The agent's runtime and project moved under its name, which frees up room and makes the page much easier to read on a phone.
