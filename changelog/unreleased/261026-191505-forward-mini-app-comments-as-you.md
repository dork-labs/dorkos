### Added

- Answer an agent from inside a mini app. A comment you type there can go to one agent you pick in Settings → Extensions, and it lands in your Direct chat with that agent as your own message. The agent treats it as if you had typed it there, so it no longer asks you to approve each step. A muted line above the message says which mini app and item it came from, and the agent's answer can show up back in the mini app under the agent's name. It only works when DorkOS asks you for a password, and each one is in the audit trail. (DOR-3325)
