### Fixed

- An OpenCode agent is now told when helpers are off in its chat, and why, so it does the work itself instead of retrying (DOR-4447)
- A Codex agent is now told when its project's own Codex settings and tools did not load at the chat's permission level, and how they would (DOR-4447)
- When an installed package's safety check blocks a command in an OpenCode chat, the agent now reads the check's reason, not just "rejected" (DOR-4447)
- When an agent tries to start a chat in a permission mode that runtime doesn't have, the refusal now lists the modes it does have (DOR-4447)
