### Added

- Share a live page with your agent using DorkOS browser, a new browser window, or a tab you choose in Chrome or Edge. Pause the agent while you use the page. Separate browser choices keep their own saved sign-ins (DOR-2929).

### Removed

- Replace the former hidden-browser setup with the three live-page choices. Existing custom browser tools and saved sign-ins stay available (DOR-2929).
