### Fixed

- **Select and copy text in the desktop app.** Messages, tool output, documents, mini-app pages, settings and profiles can now be selected and copied on Mac and Windows. Buttons, tabs, menus and sidebar rows still can't, so dragging across them stays tidy. The copy button on every code block now reads "Copy code", and it leaves off the last line break, so a command pasted into a terminal waits for you to press Enter.
