### Added

- Replacing a Community owner who has left can now finish on the server. The owner can keep ownership with one click from the email, with no sign-in, or from the community while signed in. The person the host asked for can then take ownership, signing up first if they need to. When the host uses single sign-on, only the exact account the host named can do this. Asking for a replacement is still refused for now, because the pages those emailed links open are not ready yet. It will open up in a later release (DOR-2541)
