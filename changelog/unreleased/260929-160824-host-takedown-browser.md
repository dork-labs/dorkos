### Added

- A Community host can now take down one message, one file, or the community icon from the host page, by the ID in a report. The page warns when takedowns won't keep a copy for the authorities, and lists each takedown with where its copy stands, with Try again and Release where they apply.
- When the host removes something and says why, the community's owner and admins see it under "Removed by the host" in Settings, and the person who posted it sees a one-time note with the reason.
- Each file in a message now has its own Report link, so a host can take down just that file.
