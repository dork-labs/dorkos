### Security

- Other programs on your Mac can no longer use the DorkOS app to run their own code by setting `NODE_OPTIONS` (a setting that loads extra code into Node) or by starting it with `--inspect` (a debugging switch). The app also refuses to start if its main app file was changed after it was built. Custom company certificates set through `NODE_EXTRA_CA_CERTS` keep working.
