### Fixed

- Agents no longer wrongly believe you stopped them. When a background agent finished at
  the exact moment the main agent asked permission to use a tool, the runtime cancelled
  that tool call with a message that read as if you had refused — so the agent would halt,
  apologize, and sometimes throw away finished work. DorkOS now catches that false signal,
  tells the agent it was a system hiccup and not you, and shows a status note so you can
  see what really happened (DOR-1087)
