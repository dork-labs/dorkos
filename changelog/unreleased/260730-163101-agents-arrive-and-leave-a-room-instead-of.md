### Changed

- An agent you add to a room now arrives: its row opens into place and glows once, so you can see where it went. Before, it vanished from the picker and appeared in the list with nothing connecting the two.
- Taking an agent out now collapses its row instead of making the list jump, so the **Undo** offer has something you actually watched happen.
- Opening an agent's loudness settings slides them open, and the arrow on the button turns over.
- An agent that is working now has a pulsing dot, not a still one — it is reporting something happening right now.

All of these stop moving, without disappearing, if your system is set to reduce motion.
