### Changed

- Chat links your agents write now use the `/r/dork:chat:…` form, the one link DorkOS uses for a chat, room, message or agent. These links, and `/r/dork:room:…` links, now show the same small chip in a chat or a room as other chat and channel links: the name, and whether the chat is working right now (DOR-5202).
