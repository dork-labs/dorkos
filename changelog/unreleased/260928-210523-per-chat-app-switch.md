### Added

- You can now turn an app on or off for one chat. Open the chat's details, and each app its agent was given has a switch. Turning an app off there only affects that chat. Turning it back on gives the agent the access it already has, never more (DOR-2448)
- When an agent asks for an app that its chat has turned off, the request card in the chat now offers to turn it back on for that chat and answers the agent in the same step (DOR-2448)
