### Fixed

- When an agent asks to change how a scheduled task runs, the approval card now also shows any
  mode and rules it asked for that this approval won't apply. A yes counts only for that exact
  request; the rules still wait for your own Approve. The agent is told so, instead of hearing
  nothing.
- The card now names modes the way the mode picker does, like "Never ask". Mode-change cards
  raised before this update need asking again: the agent is told the card is out of date.
