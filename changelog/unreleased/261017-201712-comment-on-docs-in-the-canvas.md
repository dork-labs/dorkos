### Added

- Comment on a markdown file open in the canvas: select some words, press Comment, and the thread appears beside the doc with its words highlighted. Reply, resolve and reopen threads, show resolved ones, and type `@` to bring an agent in. A thread says so when its words appear more than once or were removed. Part of the Docs experiment, which is off by default (DOR-2983).
