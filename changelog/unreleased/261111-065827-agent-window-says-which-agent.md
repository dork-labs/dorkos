### Fixed

- A window your agent is driving now names it, for example "Atlas is using this window", so two windows open at once are easy to tell apart. When a site needs you, the card in the chat also says "Your turn: Atlas can't see or use this window." While you have the browser, your agent can't read the page, take a picture of it, or act on it, whichever AI app it runs on. (DOR-3111)
