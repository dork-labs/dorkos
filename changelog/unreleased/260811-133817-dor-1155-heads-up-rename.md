### Changed

- The top of the sidebar is now called **Heads up** instead of **Now**. It shows the same
  things it always did: the agents waiting on you, and one line counting the ones still
  working. "Now" sounded like it meant everything currently running, so people looked there
  for an agent that was busy rather than one that needed them. Nothing moved, and nothing
  else changed (DOR-1155)
