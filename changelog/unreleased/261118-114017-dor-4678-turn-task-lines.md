### Fixed

- When an agent is refused because its turn followed a message DorkOS can't vouch for, the refusal now says so, both for a connected-app send nobody was there to approve and for a schedule mode above what that turn may set (DOR-4678)
- Agents now learn they can ask you for a looser mode or exact command rules on a schedule, and that a schedule takes at most 20 rules (DOR-4678)
- An agent listing your schedules can now tell which ones can't run, and who approved each one, when and where (DOR-4678)
- An agent listing your apps can now see which ones are waiting for you, and what an update would add since you last allowed it (DOR-4678)
- When you press Back or Forward while an agent is using the Agent browser, the agent is now told it was paused and that only you can resume it (DOR-4678)
- An agent refused a named browser profile is now told which safety check its runtime is missing (DOR-4678)
