### Added

- You can now copy a link to a chat, a message in a room, or an agent. Open the chat's menu in the chat list, a message's actions, or the agent's profile menu, and pick **Copy link**. The link opens the same thing for anyone who can open this DorkOS. In the desktop app it is a `dorkos://` link, so it still works after the app restarts. When an agent puts one of these links in a chat, clicking it opens the page right away instead of asking first (DOR-5046).
