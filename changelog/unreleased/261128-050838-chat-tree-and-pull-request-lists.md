### Added

- See what a chat led to. A chat that started other chats now shows them as a tree in the chat list: open the fold to see each spin-off and whether it is running, done, waiting for you or never started. A chat's header lists the pull requests it and its spin-offs opened, and an agent's profile lists the agent's. A private chat you can't open shows only as "A private chat" (DOR-4971).
