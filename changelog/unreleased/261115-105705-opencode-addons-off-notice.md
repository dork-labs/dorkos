### Added

- When you chat with an OpenCode agent in a project that has its own OpenCode plugins, tools or MCP servers, the chat now says how many DorkOS kept off. It says this once per chat, and the note stays when you reopen it. DorkOS doesn't run a project's own code without your yes.
