Dorian, Nov 25: match the pin to the pnpm on PATH. The Mac's Homebrew pnpm is 10.33.0 while `packageManager` pinned
10.28.2, so pnpm switched itself to the pin on every command in the repo; with HOME moved that self-install recursed
into the Nov 25 fork bomb. #4417 stops the switching; this removes the mismatch, so local runs and CI use the same
pnpm. `dependabot-lockfile-repair.yml` pins pnpm on main on purpose (DOR-4030) and refuses a package.json that asks
for another version, so both move together. `pnpm install --frozen-lockfile` passes under 10.33.0 with no lockfile
change. Revert if CI shows a pnpm 10.29-10.33 behaviour change (filtering, `pnpm deploy`, lockfile rewrites).
