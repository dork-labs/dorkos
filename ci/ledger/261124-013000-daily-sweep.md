Dorian, Nov 23 (DOR-5120): no local agent reviews an open PR; QA and the designer review everything
merged since the last release, once a day. Since #4188, `pr-gates` prints `qa-real-data` and
`design-ok` as notes only, so this list is where those reviews happen now.

`daily-sweep.yml` runs daily and rewrites one issue per release window ("Daily sweep: merged since
vX.Y.Z", label `daily-sweep`) with the PRs `design-ok.sh` or `qa-real-data.sh` flag, the same rules
that used to gate them. Ticks carry over between runs. An unreadable PR is listed for both.

First dry run (Nov 24, since v0.141.0): 46 merged PRs, 4 for design, 2 for QA, 41 for neither.

Target: every flagged PR is ticked or has a fix PR or issue within two days of its sweep.
Evaluate: Dec 1, by reading the sweep issues.

Revert if the list is wrong often enough that the reviewers stop reading it.
