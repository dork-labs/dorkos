The same instruction about a gate lived in up to four places with different wording: the script's header, `lefthook.yml`, `contributing/ci.md` and the briefs that restated them (DOR-4950). Now every gate script (`check-*`, `assert-*`, `pre-push-*`, `*-check` in `scripts/`, and `check-*.ts` one folder down: 36 scripts) answers `--help` and `-h` with one block of its own header: what it is for, where it runs, how to fix a failure or update its baseline, and its usage line. `scripts/lib/gate-help.mjs` and `gate-help.sh` print it and exit 0 before the gate does any work; without `--help` every gate behaves exactly as before (outputs compared before and after for 26 runs). `contributing/ci.md` links to `--help` where it restated a gate's fix. `scripts/__tests__/gate-help.test.ts` finds the gates by the same names and fails for one with no block, so a new gate cannot land without its doc. Nothing measurable should move: no gate's verdict, time or trigger changed. Revert if a gate's `--help` is found doing work, or the test proves slower than its 3 s bound per gate.
