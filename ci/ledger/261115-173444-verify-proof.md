Part of DOR-4456. Requiring a pnpm verify pass for the exact clean commit before
opening a PR should raise the first-head required-check pass rate to 95% within
14 days. This tracked metric is hand-audited, never scored by the collector.

The existing checks run once. Their successful wrapper writes SHA and tree proof
outside git, shared by worktrees. The PR-open procedure checks it without rerunning
a gate. An explicit escape records who, when, and the commit locally. Pre-push,
required check names, triggers, and the CI retry budgets are unchanged.

Revert if proof accepts changed source or the checker materially delays PR opens.
The coordinator wires the same checker into arm.sh after Security reviews it.
