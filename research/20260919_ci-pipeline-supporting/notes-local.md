## 5. `/git:commit` and `/git:push` commands

### `/git:commit` (`.claude/commands/git/commit.md`)

- Step 1 (unless `--no-verify`): **full** `pnpm lint` and **full** `pnpm typecheck` in parallel (`:46-54`), i.e. every package, with `^build`. Then `git commit` fires lefthook pre-commit, which runs `turbo lint --affected` and `turbo typecheck --affected` again (mostly cache hits after the full run, but the full run itself is the expensive redundant step: 898s typecheck was measured for the unscoped form, `lefthook.yml:21`).
- Step 3 stages with **`git add -A`** by default (`:83-87`), contrary to the project memory rule "never `git add -A` with concurrent writers" and risky in the shared main checkout.
- The skill's `--no-verify` flag only skips its own Step 1; Step 6 never passes `--no-verify` to git (`:121-143`), so lefthook still runs (good, but the flag name misleads).
- Hard-codes attribution `Co-Authored-By: Claude <noreply@anthropic.com>` (`:127-128,139-140`), which differs from the session's current attribution guidance.
- Does not run tests, format check, or any `check:*` gate.

### `/git:push` (`.claude/commands/git/push.md`)

- Step 2: **full** `pnpm lint`, **full** `pnpm typecheck`, **full** `pnpm build` (`:32-42`). `pnpm build` = `dotenv -- turbo build` over every app including the Next.js site (5m10s measured, `site-build.yml` comment) and desktop/obsidian. Then `git push` fires pre-push (format check + affected tests).
- Does not run tests itself, nor `lint:root`, `format:check`, or `check:*` gates. So it spends the most time of any local path while still missing the CI-only gates.

### 6.2 ESLint: up to 6 runs per change

PostToolUse per-file (`lint-changed.sh`) → `/git:commit` full `pnpm lint` → pre-commit `turbo lint --affected` → `/git:push` full `pnpm lint` → `pnpm verify` (`lint:root` + `turbo lint --affected`) → CI full `turbo lint` + `lint:root` (`lint.yml:152,181`). Pre-commit does **not** run `lint:root`, so edits to `scripts/`, `.claude/`, `.agents/` are only linted at the per-edit hook (which does lint root files, `lint-changed.sh:42`), verify, and CI.

### 6.3 Typecheck: up to 6 runs, plus LSP

PostToolUse `typecheck-changed.sh` (9 of 24 workspaces; no `^build`) + typescript-lsp plugin diagnostics → `/git:commit` full `pnpm typecheck` → pre-commit `turbo typecheck --affected` → `/git:push` full → `pnpm verify` affected → CI full `turbo typecheck` (`typecheck.yml:255`). Pre-push does **not** typecheck.

### 6.4 Tests

`pnpm verify` affected (`-- --run`) → pre-push affected (`-- --run`, same key, so a green verify makes pre-push a cache replay) → CI PR affected shards → merge_group full shards (different passthrough args, cold cache, so no sharing with local).

### 6.5 `any` policy inconsistency

`check-any-changed.mjs` **blocks** every `any` (exit 2), including in tests, while ESLint has `no-explicit-any: 'warn'` in `packages/eslint-config/base.js:51` and `'off'` for tests in `packages/eslint-config/test.js:4-6`, and no lint script uses `--max-warnings` (`lint.yml:31,142`). So the rule is enforced only against agents editing through Claude, not at commit, push, or CI, and it contradicts the test config.
