Codebase Migration Orchestrator (staging)
@codebase-migration-orchestrator-v2
  • Mentions are never silently truncated — wrap within the line (overflow-wrap:anywhere + box-decoration-break:clone).
  • Names & handles in rows/cards ellipsize to one line; the fixed avatar never shrinks; the hover card is the full-value escape hatch.
  • No handle → omit the subtitle (never fake one; matches the picker's "No @name").
  • No emoji on a filled agent disc → the fallback letter needs contrast against the identity color (light vs dark), not assumed white.
  • Multi-codepoint emoji (flags, ZWJ like 🧑‍💻 / 🏴‍☠️) must be constrained to the disc.
  • Unresolved @thing → plain text, no pointer, no pill.
