# Plans

Keep plans cited by current docs, guides, ADRs, specs, source, tests or scripts, along with their dependencies. Plans named by open issues, projects or pull requests also stay.

Unreferenced plans for shipped or abandoned work can leave the checkout. Git history keeps them: use the [plans tree before the November 2026 cleanup](https://github.com/dork-labs/dorkos/tree/885b00fa627fad4bcefa918a93105d427f1a0f7c/plans) to recover a removed plan.
