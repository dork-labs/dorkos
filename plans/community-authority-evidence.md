# Community authority and recovery evidence

**Scope:** bounded research for [DOR-2345](https://linear.app/dorkspace/issue/DOR-2345/reconcile-community-authority-and-isolation-coverage), with the Community slice of [DOR-2349](https://linear.app/dorkspace/issue/DOR-2349/map-cross-boundary-recovery-guarantees-to-release-evidence). **Source baseline:** `5794f638160a68811382347356fd29b31ee2e911` (2026-09-27). Every `path:line` below means that line in this immutable commit, not the current working tree. Test titles and source paths were inspected; this research did **not** rerun their suites or certify a release gate. Existing dated run receipts are identified separately. Live tracker status must be checked before execution.

The chain for a human action is: local caller → saved owner-qualified connection ref → pinned remote origin and immutable community UUID → the saved personal grant's remote member. An agent action substitutes one explicitly enrolled agent bearer. The browser cannot nominate an acting member for a human post. This is implemented in `apps/server/src/routes/community-connections.ts:55-85`, `apps/server/src/services/communities/remote/connection-store.ts:27-44,246-252,395-402,478-485`, `apps/server/src/services/communities/remote/remote-community-adapter.ts:306-334`, and `apps/community/src/tenant-context.ts:34-83`. The remote host checks the selected tenant and current principal again at the operation boundary; see `apps/community/src/routes/events.ts:223-276,309-350` for the stream example and [the tenancy receipt](../specs/community-tenancy-contract/05-isolation-receipt.md) for the wider route family.

Path shorthand in the tables resolves as follows: local routes `community-connections.ts` and `remote-communities.ts` live in `apps/server/src/routes/`; local connection and adapter sources plus `pairing-service.ts` live in `apps/server/src/services/communities/remote/`. Their named tests live in sibling `__tests__/` directories. Host `tenant-context.ts` is in `apps/community/src/`; host `events.ts` is in `apps/community/src/routes/`; host integration tests live in `apps/community/src/__tests__/`. `community-two-desktop/*` lives in `apps/e2e/`; `community-switching-proof.spec.ts` is in `apps/e2e/tests/connections/`; `community-rapid-switch.test.tsx` is in `apps/client/src/app/__tests__/`. All lines and exact test titles refer to the source baseline above.
