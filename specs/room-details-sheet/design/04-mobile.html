Four rows, 48px each, nothing truncated

Every consequence is on screen at once — which is precisely what the desktop hover preview buys you one rung at a time. On touch you read all four instead of hovering each; the model lands in one glance rather than four. No truncation at any width, the native grouped-list idiom, and the ⋯ disappears: Remove lives at the foot of the expanded row, so there is no menu portalled inside a drawer at all.

What I checked, so this isn't guesswork

  • Breakpoint is 768px (use-is-mobile.ts), drawer below it.
  • One thing I expected to be broken isn't. SelectTrigger defaults responsive = true → h-11 md:h-9, so today's mode dropdown is already 44px on touch. Whatever replaces it has to hold that line.
  • DrawerHeader is text-center sm:text-left — the sheet's header is centred on a phone today. An inline-editable name centred on screen is wrong; this sheet overrides it.
  • No safe-area inset on DrawerContent. DrawerFooter is 16px against a 34px home indicator. Needs verifying on a real device — and if it's wrong, it's wrong for every drawer in the app, so it gets fixed in the primitive.
  • AgentChipPicker already did the hard touch work and none of it may be lost: 44px option rows, a chip-remove hit area deliberately sized to 6px/4px so it doesn't eat the input (measured: 1.9% of the field stolen at two chips, 10.6% at six), and a list floor so a landscape keyboard doesn't leave you typing into nothing.

B

Adaptive — segmented on desktop, rung list on touch (recommended)

Two renderings of one control, sharing one model and one set of tests. The phone gets the idiom it deserves and loses nothing — it trades a hover it cannot perform for four explanations it can read at once. Costs a second layout in one component.

Uniform — the segmented control everywhere

One layout, less code, easier to keep honest. But it truncates the labels at 390px and breaks at 320px, and the labels are the only thing telling the rungs apart. Would need shorter words, which is where the current five-sentence mess started.
