## Accepted deviations

- **In-chat connect card deferred; markdown is v1.** `connector.start_connect` returns plain markdown (sign-in link + custody disclosure + "tell me when you've signed in"). The rich in-transcript card stays a named deferred enhancement, exactly as spec §Non-Goals froze it.
- **DirectTransport (Obsidian) is honest-notice, not parity** (spec OQ4, decided at EXECUTE): read surfaces answer empty; credential/connect writes refuse with a clear "open the web cockpit to manage connections" notice. Never a silent failure.
- **Raw-MCP config is boot-only** (spec OQ3 accepted): `connectors.rawMcpServers` is read at startup; edits take effect on the next boot. Documented in the config docs and `docs/connectors/raw-mcp.mdx`.
- **Beyond-spec strengthening from review:** credential delete now revokes live surfaces, not just new connections — the bootstrapper's `onUnregistered` hook drives `SessionConnectorService.invalidateProvider` (attached sessions degrade to the standard null-branch warning) and `NangoProxyMcp.clear()` (per-account tokens die). The Nango proxy mount gained `validateMcpOrigin` (same DNS-rebinding posture as `/mcp`).

## Review protocol

Every slice ran a deep adversarial review **pre-PR** (dispatched reviewer agents against the branch), so the PRs opened with `review:light`; all landed approve-with-nits with 0 important findings, nits applied before or immediately after opening. The reviews used **mutation testing** to prove the security tests bite: removing the attach tier gate turns the gate-refusal test red; letting a caller-supplied `authorization` header through turns the header-displacement test red; deleting the disclosure-before-sign-in ordering, the `window.open` consent pin, or the `?type=connector` URL-enum branch each turns its test red. Slice A's config migration was driven through a real `conf` store over a real file, including corrupt-shape recovery.
