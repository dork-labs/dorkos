7 · Two new core pieces: "start a chat here" and helpers' items

Two questions on one page. Pick one in each. These are core DorkOS features, so any extension can use them, not just flow.

Question 1 · You click "Triage now" (or "Set up flow here", "Reconnect"). What happens?

An extension asks DorkOS to start a chat in a project with a command. It must never run on its own.

A

A new chat opens with the command typed in, not sent (my pick)

You see exactly what will run, and you press Enter. You can edit it first. Nothing runs until you do.

A small "Start this?" box, then it runs

One more click, but you stay where you are. The chat runs in the background, and a note tells you where it is.
