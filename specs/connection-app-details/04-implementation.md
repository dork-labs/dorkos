## Found and fixed along the way

- **DOR-2467 (#2220):** every DorkOS-account request had failed since 2026-09-19 (tenant lookup needed a unique index production no longer has). Fixed without a production change.
- **DOR-2468 (#2233):** a stalled disconnect or resume is re-sent until it settles; the panel says why it's waiting and never claims a retry that isn't happening.
- **Connected-app actions (#2242):** every action was refused because validation filled schema defaults before an exact-match check. One shared check (`@dorkos/shared/connector-arguments`) now validates without defaults and sends exactly what the agent sent.
- **Merge-queue browser suite (#2248):** cloud-api's build deleted `dist/` while another leg's Vite scan read it. Clean now runs only before publishing.
- **Midnight flake (#2259):** a panel test crossed midnight; its clock is pinned.
