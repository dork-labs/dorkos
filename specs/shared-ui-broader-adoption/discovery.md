## CSS and portal checklist

- Semantic color classes become dui-*; plain border utilities receive an explicit package border color.
- Icon variables used by selected modules: --size-icon-md, --size-icon-sm, --size-icon-xs. Package defaults and client scale bridges must cover all of them.
- Radix geometry variables stay unchanged. Audit animate-in/out, fade, zoom, slide, collapsible and duration utilities in the installed distribution.
- Dialog, AlertDialog, Sheet, Popover, HoverCard, Tooltip, Select, DropdownMenu and ContextMenu portal paths must consume UiProvider; explicit Portal container props win.
- Preserve immediate menu dismissal, dialog close controls/gutters/scrolling, responsive sizes, ref forwarding, select scrolling and side offsets.
