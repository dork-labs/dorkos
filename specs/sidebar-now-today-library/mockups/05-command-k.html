The rules
  • ⌘K finds things, not words. Agents, sessions, rooms, actions — by name and title. Message-content search stays a separate surface (a recorded product decision — the Slack ⌘K / ⌘F split — and it holds). ⌘K's last row hands off to it. So C's "archived overnight, find it in ⌘K" means by title and recency, which is how people actually recall conversations.
  • Sessions become first-class citizens — the single biggest gap. Cross-agent recents feed the index (the endpoint already exists; the sidebar uses it, the palette never did). Rows reuse the sidebar grammar exactly: avatar + Agent › title + origin mark + time.
  • One frecency store for everything — the Slack-bucket algorithm already implemented for agents extends to sessions, rooms, and actions, keyed by type:id.
  • Search + act (Raycast rule): every row shows its shortcut inline — ↵ open, ⌘↵ new session with that agent, passive shortcut learning for free.
  • Archived rooms become findable (the API flag exists; the client never passes it) — labeled, never hidden.
Dead ends found in the audit — fixable this week, no redesign needed
Enter on a slash command does nothing. The Commands group is a read-only listing — no select handler at all.
"Continue: session" closes the palette and goes nowhere. The one recall affordance that exists is a no-op.
Recent-session rows in the agent drill-down are inert too — and extension-contributed actions silently do nothing (their handler registry is written but never read).
