Read the grammar, not the rows
glyph = what kindname = who› title = which threadtrailing = status
Session: avatar + Agent › title. Channel: # + name. DM: avatar + name, no ›. The "›" is the session marker — its absence means "this is the place itself, not a thread."
  • Same agent, many sessions → the name repeats, on purpose. A repeated anchor is how the eye clusters: scan the "who" column, find DorkOS twice, then the titles do the telling. Structural grouping (nesting them under one header) would make Today's shape churn as sessions come and go — worse than the repetition it saves.
  • Rows never jump while you watch. Today sorts by your last interaction, not by agent activity. A working agent pulses in place; it doesn't leapfrog. (Activity-sorted lists shuffle constantly with 4 agents live — unusable.)
  • Two lines only when there's something live to say. Working rows earn a status line with the verb; idle rows stay one line with a timestamp. Height differences carry meaning.
  • Distinguishers for same-agent sessions, in order: title, live verb, time. Titles are auto-generated from the first message today already — the switcher (⌘K or the "2 live" chip) is the fallback for deep stacks.
  • Overload is capped structurally: Now shows max 3 + rollup, Today shows ~8 with automated behind the reveal, everything older lives in ⌘K. The crowded morning never gets taller than this mock.

Scroll-to-active — yes, with three guardrails

  • On switching conversations, the sidebar scrolls the anchor row into view. Since the anchor pins to Today's top, this normally means a short glide back up if you'd wandered deep into the Library. One target, fully deterministic.
  • It never auto-expands a collapsed section. If the agent also appears in an expanded Library section, that row gets the active tint too (same item, two places — the Notion-favorites pattern), but we don't unfold anything you folded. Your structure is yours.
  • Reduced motion = instant jump, no glide. And scrolling only happens on conversation switch, never while you're reading — the sidebar must never move under your cursor.
