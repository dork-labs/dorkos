# Connections that never leave you stuck — ideation

**Problem.** When something goes wrong with a connection (a link ends, a sign-in expires, a key is removed, a sync is refused), Connections often shows a green row, a retry that cannot work, or a row that cannot be removed; agents guess action names and are refused without a next step.

**Direction.** One readiness truth computed on the server and rendered everywhere; every problem has one fix or none needed; the person's choice is final locally; agents ask by level; levels are promises.

Decisions, principles and the MoSCoW plan: [design-decisions.md](design-decisions.md). The audit that grounds it: [connections-audit.md](connections-audit.md).
