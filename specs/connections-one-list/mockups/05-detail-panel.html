One choice — where does it open?

A

Side panel (recommended)

Slides in from the right, the list stays visible behind it. On a phone it slides up from the bottom. It still gets its own link, so the chat card's "Change" button can open it directly.

B

Its own page

/connections/gmail. More room for activity history later, but you lose the list, and it feels heavier for a two-second change.
