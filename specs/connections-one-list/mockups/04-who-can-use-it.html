More control. But "all today" vs "all forever" is a subtle difference most people won't get on first read, and it's one more thing to think about.

How it shows up afterwards

The row says "Every agent" instead of a count. The chat card never offers "every agent" — in chat you're answering for one agent, so it stays one agent. "Every agent" is a planning choice, so it lives on the page.

Heads up — this is new server work

Today, access is always granted to one named agent at a time (spec: specs/white-label-connections/). "Every agent, including future ones" needs a new kind of grant. That's doable, and it should get a short decision record, since the spec chose one-agent-at-a-time on purpose.
