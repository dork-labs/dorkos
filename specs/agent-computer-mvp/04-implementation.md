## Decisions

Use one direct Lima VZ Linux VM on Apple Silicon, with no host mounts, shared vendor sign-in, or container layer. The brain is OpenCode inside the VM. A metadata-only host anchor maps structurally to `/home/agent/project`. Credits callbacks are explicitly off for this runtime. An authenticated bounded PNG framebuffer and typed input helper show and control the same X display the guest agent uses. Human takeover freezes the agent runtime cgroup and fences input with a generation-bound lease. Stop retains the disk.

## Implementation adjustments

The final backend contract is `services/computers/backend/types.ts`; lifecycle service/storage belong to the integrator and authenticated routes to the backend worker. Runtime source is `runtimes/opencode/computer/`. A bounded authenticated PNG/input helper replaces VNC. Guest secrets are generated inside Linux; the separate desktop UID owns Xauthority, and Chromium has no CDP listener. Exact DHCP renewal is allowed alongside DNS and the scoped bridge. The short instance name `computer` fits Lima's Unix socket limit while a private UUID establishes durable ownership. Stop may force power off only after revalidating exact ownership, configuration and generation; unconfirmed state stays uncertain.
