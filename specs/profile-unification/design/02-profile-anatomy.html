What the Overview answers, in order

1 · NowIs it doing something right now? Uses the real live-turn signal rooms already have (not the 60-min mesh window). Idle → “Last active 3 h ago”. Never → “Hasn’t run yet — say hi”.
2 · AboutWhat is it: description, runs on, personality, folder (copy/reveal), joined. Inline-editable if you manage it. Read-only otherwise.
3 · RecentWhere has it been: last sessions, rooms it’s in, next scheduled run. Each row is a link.
4 · ToolkitWhat can it use: skills · MCP · tool groups, as counts. One tap to the Toolkit tab.

Actions

MessagePrimary, always first. Agent → opens/continues its session (or DM). Person → DM. Bridged person → DM via that platform.
ManageOnly for agents you manage. Jumps to the Config tab. This is the old “Manage” / “Agent hub” verb — one door now.
⋯Copy @handle · Add to room · Set as default · Block · Unregister · Delete. Danger at the bottom, typed confirm stays.

Naming (hub is retired)

Right-panel tab Agent Profile → Profile (icon: the identity face itself when docked to an agent)
Verbs everywhere Agent hub, Manage, Open profile → View profile (one verb). “Manage” survives only as the button inside the profile.
Shortcut ⌘⇧A “Agent profile” → toggles the docked Profile. Keep.
Deep link ?profile=<id>&tab=config — one address for both homes. ?panel=agent-hub&hubTab= redirects.
Code features/agent-hub folds into features/profile. Store: useAgentHubStore → profile store. Personality picker + management menu move with it.
Inner tabs Overview · Sessions · Config · Toolkit — “Config” is techy; “Setup” is an option. Your call.

Click 1 or 2. Then tell me: does the Overview order feel right, and Config vs Setup?
