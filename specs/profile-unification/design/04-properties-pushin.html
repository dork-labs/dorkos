On push: the portrait header shrinks into the strip (same face, same colour wash), the list slides left. Back reverses. ~250 ms, position-only. No celebration.

Rules that keep it calm

Two kinds of rows▾ = quick pick, opens a small popover (Runs on, Personality). › = a page, takes the whole panel. ⧉ = copy. Nothing else.
Every pushed page has the same top“‹ Profile” + the strip. Then a title. Then the content owns the height. Search only where the list can grow.
Groups by spacing, not labelsIdentity · Work · Toolkit · Ownership. A gap says enough.
Read-only is the same list, minus arrowsSomeone else’s agent, a person, DorkBot’s locked fields: same rows, no ▾ / ›, no Save.
Managed by → is a profile tooTapping “You” pushes your own profile onto the same stack. Profiles chain.
Kebab is only the rare stuffSet as default · Copy @handle · Block · Unregister · Delete. Danger last, typed confirm stays.

One thing this changes: editing yourself

The old rule was “drawer to view, Settings › Profile to edit”. With B, your own profile’s rows (Name, @handle, Photo, Email) are the controls — same as an agent’s. That makes Settings › Profile a second door to the same room.

1

Edit in place, drop Settings › Profile (recommended)

One rule for everyone: if it’s yours, the row is the control. Settings loses a tab. Account menu: View profile · Settings · Sign out.

2

Keep both

Rows editable in the profile, and Settings › Profile stays as a form for people who look there. Two doors, same room.
