## What is not done (deliberately), and why a fresh reader must not "improve" it back

- **No Message button on people, Telegram guests, or someone else's agent** — no DM route to a person exists; a button that does nothing is the failure mode this design removes (spec §8). `design/05-states-final.html` predates that decision.
- **Someone else's agent shows only about · runs on · rooms** — its sessions, tools and instructions are private, and About/Message need a local manifest/projectPath another person's agent never has.
- **DorkBot's Personality is a control** (amended); its name, face and description stay locked (`SYSTEM_PROTECTED_FIELDS`).
- **The sidebar's fallback door for an agent the fleet cannot name opens the docked panel, which says the agent is gone** — not a profile; the branch is near-unreachable (both ends read the same payload). Words are honest about it; do not describe it as opening a working profile.
- **`explicitAgentPath` latched by a link stays the panel's subject for the session**, exactly as a click's does (DOR-227). Closing the panel while it shows another agent's profile records "closed" for the _session's_ agent.
- **A pending link mark for an agent you never visit** sits through exactly the arrival bind and is spent by the next bind for anyone else; a link followed on `/team` is "arrived" by the first session you enter.
- **`?profilePage=` opens only a page a row of THAT profile offers** — never an editing page on someone else's card.
- **Accessible labels say "Open {name}’s profile"; visible items say "View profile."** Both on purpose.
- **Right-panel tab icon is the Lucide `User`**, not the identity face (registry takes a `LucideIcon`).
- **`hubTab=`/`?panel=agent-hub`/`?agent=<legacy tab>` survive only as redirect inputs** in `use-profile-dock-deep-link.ts` / `dialog-search-schema.ts` / the stored-layout rename map — that is the legacy door, not drift.
- **The injected-prompt preview is client-side** so it can follow the draft; it deliberately omits the DorkOS-knowledge, `<user_profile>` and `<env>` blocks.
- **Rooms rows show room names** (`#team, #general, +7`), not a count — richer than §1.4's table.
- **"Set as default" is absent from the kebab once the agent already is the default** (the header badge says so) — not present-and-inert; §1.4's "system agent → Set as default · Copy" reads unconditional.
- **The bridged person's "First seen" row is coded but never served** (`TeamPersonFacts` has only `lastSeenAt`); it stays absent rather than reading "—".
