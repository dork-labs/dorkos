Account roles move to a Flow settings tab

DorkOS itself keeps each account's name, color and usage. Everything about how flow spends the accounts lives in a "Flow" tab that the flow plugin adds to Settings. Without flow, that tab and its controls don't exist.

A

A separate "Flow" tab, with a pointer from Runtimes

Runtimes stays about the accounts themselves. A one-line note links to the Flow tab, where each account gets its role. The Flow tab only appears when flow is installed.

Flow adds its controls right inside the Runtimes rows

Everything about an account stays in one place: Runtimes, where you already manage accounts. Flow plugs its role switch into each row. This needs DorkOS to add a new add-on slot inside the accounts list (a bigger core change), and it mixes two concerns on one page.

My pick: A. It uses the add-on Settings tab DorkOS already supports, so no new core plumbing is needed. It keeps "what accounts I have" apart from "how flow spends them", and the note in Runtimes makes the Flow tab easy to find. In the terminal, flow accounts set edits the same settings.
