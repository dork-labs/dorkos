When a session's account runs out of usage

By default, work moves to another account automatically (you can switch this to "ask me" in Settings → Flow). The new session picks up in the same folder and branch from a short checkpoint. It starts a fresh chat with a summary, because the old chat can't move between accounts.

A

A banner above the message box

It stays in view where you'd type next. In automatic mode it counts down and moves the work, and you can stop it. Afterwards it links to the new session.

B

A card in the conversation, at the point it stopped

It reads as part of the story: here's where it stopped and what happened next. It scrolls away with the chat, so the status-bar chip and the sidebar dot carry the "out" state after that.

My pick: A. A limit blocks what you'd do next, so the notice belongs where you'd act, and it stays visible until it's resolved. B is nicer as history, but it's easy to miss once the chat moves on.
