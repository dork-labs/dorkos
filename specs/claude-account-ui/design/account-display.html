Which Claude account is this session on?

Today the account only shows in a tooltip on the runtime chip. Here are three ways to make it obvious. Each account gets a color and a short name, set in Settings → Runtimes.

A

Its own account chip in the status bar

A new chip with a color dot, the account name, and two tiny bars (5-hour and week). It turns amber when the account is near its limit and red when it's out. Click it to open the details.

B

Folded into the runtime chip

The existing runtime chip also names the account, with a color ring. There's no new chip, so the status bar stays short. Usage stays in the separate usage chip that already exists.

~/dorkos⎇ main ◆ Claude Code · Opus · Acct 2 5h 40% · 7d 72% ctx 38%
C

Everywhere a session appears (A, plus the sidebar and header)

The chip from A, plus a color dot on every session in the sidebar and a name badge in the session header. You can tell at a glance which account each running session is spending, without opening it.
