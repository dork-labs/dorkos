DorkOS finds Claude accounts already on your computer

A new user with several accounts shouldn't have to type folder paths. DorkOS can spot account folders (like ~/.claude2) and offer to add them. Nothing is added without a click. A folder that looks company-managed is flagged, not hidden: you decide. How should it offer them?

A

A "Found on this computer" list under your accounts

It sits right where you manage accounts, and each folder gets its own Add button. It disappears once everything is added or dismissed.

B

One notice at the top that opens a picker

It's quieter: one line and one button. The folders appear in a small dialog with checkboxes. It's one extra click, but the accounts list stays clean.

My pick: A. The found folders sit exactly where you'd add them, and you can add one without leaving the page. A company-managed folder shows a flag and a plain (not highlighted) Add button, so adding it is a deliberate choice. Dismissed folders stay hidden.
