          `null` on a system agent and on every person. `agent.recentlyActive`
          restates `healthStatus === "active"`, which the mesh defines as "seen
          within the last hour" — it is not a live-turn signal. Degradation
          follows ADR-0310, and covers EVERY read rather than just the two
          registries: `authors`, `agents`, `operator` (the account lookup) and
          `config` each contribute a `warnings[]` entry on failure while the
          rest still return, so a roster that cannot say your name still lists
          your agents and this endpoint has no 500 path through its sources.
          `warnings` is omitted entirely when every source read cleanly — never
          sent as `[]`.'
