          Read the DorkOS audit log: every action anyone took, person or agent,
          newest first. Filter by actorId (who did it), targetId (what it was
          done to), action (a prefix such as "config." or "runtime.tool_used"),
          operation, sessionId, and a since/until time window. It comes a page
          at a time (limit, at most 200): pass nextCursor back as cursor for the
          next page; nextCursor is null on the last one. You see every action
          and every agent's work; a person's private chat and sign-in details
          are not shown to agents.
