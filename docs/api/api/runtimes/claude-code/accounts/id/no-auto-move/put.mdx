      - content: "With `noAutoMove: true`, DorkOS never moves a room agent whose account
          ran out to this registered account on its own; a person may still move
          one there. `false` lets it be picked again. Recorded in the permission
          history with an Undo, rather than as a config change. Main (`default`)
          has no registry row, so it answers `404`. Only a person may call it: a
          request from another site, a caller that names itself an agent
          (`X-DorkOS-Agent`), and, with Require login on, a caller without a
          signed-in session are refused with `403`. With Require login off, a
          local caller that sends no agent header is trusted, and an approved
          extension's own browser code shares the app's page, so it passes in
          either posture. Each change is recorded in Activity."
