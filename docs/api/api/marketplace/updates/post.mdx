      - content: Reinstalls every installation in view whose check is
          `update-available`, each in the scope it was found in, one at a time.
          A failed reinstall is reported on its installation as `applyError` and
          the rest carry on. Each reinstall is authorized as
          `marketplace.install` before anything runs. A batch that would need a
          person to approve each install is refused
          (`batch_update_needs_approval`); use the one-package route instead.
