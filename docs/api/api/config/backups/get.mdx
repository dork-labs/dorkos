          Every copy a DorkOS writer made in `<data dir>/backups`: daily and
          before-update copies, both the `dork-auto-` ones DorkOS prunes and
          older `dork-` ones it never touches. Only regular files with a
          writer’s name are listed; symbolic links never are. Person-only: a
          caller naming itself an agent, an approval token, a program
          credential, another site, or a request from another computer (except
          the owner over an encrypted connection) is refused before anything is
          read. There is no MCP tool for this.
