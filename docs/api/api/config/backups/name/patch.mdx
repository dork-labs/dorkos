          **Preview.** This operation may change in any release.


          Copies one older `dork-` copy into an existing folder inside the
          directory boundary or on an external drive (`/Volumes/<drive>/…`),
          never the data folder. The destination is resolved once to its real
          path, so a link is followed and every check reads the folder written
          to. Nothing there is overwritten. The copy must match in size and pass
          SQLite’s `integrity_check`; only then is the original removed, and
          only if unchanged. A failed check deletes the new file and keeps the
          original. Person-only: a caller naming itself an agent, an approval
          token, a program credential, another site, or a request from another
          computer (except the owner over an encrypted connection) is refused
          before anything is read. There is no MCP tool for this.
