          **Preview.** This operation may change in any release.


          Every chat this DorkOS knows for one agent, ended ones included,
          newest first: its title, a ready markdown link, when it began, its
          runtime, and the chat that started it. Chats the agent ran on another
          computer are not listed. A person’s own chat is left out for an agent.
          For the chats running right now, use running_chats. Page with `limit`
          and the returned `nextCursor`. Use the link, never the id, when you
          tell a person about a chat. agentId is the agent’s id or its
          dork:agent: reference.
