          Write new text to a file that already exists under `cwd`; it never
          creates one. With `expectedHash` (or `expectedContent`) the save is
          refused, unchanged, when the file changed since it was read, and the
          refusal carries the file as it is now. A chat canvas’s document save
          (`documentSave`) is the owner’s only. A person’s door: agents change
          files with their own tools.
