      - content: >-
          The standing permissions that are live right now: which agent, which
          action, and when each one runs out. A permission nobody can find is a
          dark pattern, so this is the list the DorkOS app shows in both places
          it offers to end one. Expiry is applied here rather than left to a
          sweep, so a permission whose window has closed is already gone from
          this list.


          Authorized like deciding an approval, NOT like reading the pending
          list, and the difference is deliberate. A pending card is meant to be
          agent-readable. This list is prospective: it says which irreversible
          action will go through silently right now and the minute the window
          shuts, and it names other agents' pairings. So a caller presenting an
          agent identity or an approval token is refused.


          It carries what the DorkOS app renders and nothing more. Who opened
          each permission, when, under which posture, and which card it came
          from are recorded in the `approval.grant_created` Activity event
          instead, which is where an audit question belongs.
