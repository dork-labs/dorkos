---
title: Agent browser
description: Share a live browser page with the agent in your current chat.
---

Open **Browser** from the right panel’s **+** menu. Choose where the page opens.
Your agent uses that same live page. You can click, type, and navigate while it works.
This is the Agent browser. The older signed-in browser uses a separate hidden page.

## Choose a browser

**DorkOS browser** opens the page inside the desktop app’s right panel.
It is the desktop default. Its saved sign-ins are separate from your usual browser.
Chrome extensions do not run inside this view. It stays in the right panel;
it cannot pop out into a floating view.

Some sites open an extra sign-in window. These windows are for you;
your agent stays on the original page. Finish signing in, then close the extra window.

If your agent stops because a site needs you, a card appears in the chat.
In the Mac app, the card offers **Sign in**. It opens a plain sign-in window outside the panel,
and your agent continues in its own window. Every agent that uses the Agent browser can use that sign-in.
Only sign in to accounts you're happy for all of those agents to use.
This hasn't been tested on an installed Mac app yet.

**New browser window** opens a visible Chromium window with separate saved sign-ins.
A window your agent is driving has an orange frame. The sign-in window a card opens for you keeps your normal colours.
DorkOS keeps those sign-ins when you close and reopen it. Your usual tabs stay separate.
This is the default when you use the local npm-installed web app.

These choices open pages on the computer running DorkOS and need a graphical desktop.
The npm web app cannot put a native browser inside its page.
Choose **New browser window**, or use the desktop app for **DorkOS browser**.

Only the selected page is shared with the agent in your current direct chat.
A browser opened from Rooms stays human-only.

## Pause, close, and reconnect

**Pause agent** stops new browser actions. You can still use the page.
An action already started may finish; pausing does not undo it.

If you navigate or the page changes, the agent must read it again before acting.
An uncertain action is never repeated automatically. Check what happened before continuing.

Closing the panel hides the page. **Disconnect** ends sharing.
Disconnect closes the browser opened by DorkOS. Its saved sign-ins are kept.
If an agent is waiting on you in the browser, **Disconnect** also ends its task.
If the browser closes, choose **Reconnect** to open it again.

## DorkOS Cloud stays yours

Agents can't open DorkOS Cloud or dorkos.ai in a browser DorkOS gives them.
You can still open them yourself in the shared page.
Your agent can't read or act on a page from either site.
If it tries, or a link takes it there, it pauses. Choose **Resume agent** once you have moved on.

Saved sign-ins for older browser tools never keep a DorkOS sign-in.
DorkOS removes one saved by an earlier version the next time it starts.
A browser tool DorkOS can't keep off these sites is left out of the chat.

## What DorkOS installs

DorkOS includes the Playwright library. You do not install Playwright separately.
**New browser window** downloads the matching Chromium browser on first use.
The library and browser are separate downloads, and DorkOS keeps their versions paired.

The desktop view uses Electron’s built-in browser instead.
Some websites restrict sign-ins from embedded browsers. Use **New browser window** for those sites.

This release pins Playwright to 1.63.0 and its managed Chromium to version 153.
Local browser behavior has been verified on macOS. Windows desktop remains an early alpha;
Windows and Linux local-browser behavior still require platform verification.
These choices are for DorkOS running on your computer.

## Previously configured browser tools

Existing custom browser servers and saved sign-ins are kept.
The older **signed-in browser** uses Playwright MCP and a separate hidden page.
It does not share the live page you view in the Agent browser.
Use **Browser** for the two live-page choices above. Existing custom tools remain in **Toolkit**.
The older `dorkos browser login`, `status` and `forget` commands still manage their saved sign-ins.
Those saved files are separate from the new Browser choices.
An older signed-in browser may still show its original name. Its saved sign-ins are kept.
