---
title: Agent browser
description: Give each agent its own browser, and lend it yours when it needs your sign-ins.
---

Open the **Agent browser** from the right panel’s **+** menu, where it is listed as **Browser**.
Each agent gets a browser of its own. It starts signed out and opens in its own Chrome window,
apart from your usual tabs and from every other agent’s browser.
You can click, type, and navigate in that window while the agent works.
This is the Agent browser. The older signed-in browser uses a separate hidden page.

## Your agent’s browser

In a chat with an agent, the panel names that agent’s browser, like **Scout · browser**.
It says **This browser opens in its own window.** **Show window** brings the window to the front,
and **Close browser** closes it. A window your agent is driving has an orange frame.
DorkOS keeps its sign-ins when you close and reopen it.
All of one agent’s chats share its sign-ins. Other agents never see them.
It uses Google Chrome if you have it, and Chromium if not.

If your agent stops because a site needs you, a card appears in the chat.
It says the site needs you to sign in, or wants a person to continue.

When a site needs you to sign in, the card offers **Open sign-in window**. It opens a plain sign-in window just for you, in your normal colours.
Sign in there, then press **Done signing in** on the card. On a Mac, closing that window isn't enough, because Chrome keeps running.
Your agent then returns to the same page and carries on in its own window.
That sign-in stays in this agent’s browser, unless you shared yours (see below).
Anything you had typed into a form on that page is lost, so check it before you hand it back.
This hasn't been tested on an installed Mac app yet.

When a site wants a check only a person can do, like a bot check, the card leads with **Show window**.
Do the check in your agent’s window, then press **Continue** to hand it back.
If the check turns out to want a password, use **Sign in instead** on the card rather than typing it in the agent’s window.

These windows open on the computer running DorkOS and need a graphical desktop.

## Your own browser

Open **Browser** outside an agent’s chat and you get **Your browser**, which is for you.
Agents can’t use it unless you share it. Choose where it opens:

- **In DorkOS** opens the page inside the desktop app’s right panel. Its saved sign-ins are separate
  from your usual browser. Chrome extensions do not run inside this view, and it can’t pop out into a
  floating view. The npm web app can’t put a browser inside its page, so this choice needs the desktop app.
- **In its own window** opens a visible browser window on the computer running DorkOS, with separate saved sign-ins.

Some sites open an extra sign-in window. Finish signing in there, then close it.

## Share your browser with an agent

Sometimes an agent needs a site you are already signed in to. Only you can lend it **Your browser**,
and only by hand. In the agent’s chat, the panel says **This agent has its own browser.**
Press **Share yours**. DorkOS asks you to confirm: the agent will use the **Your browser** window
(the one that opens **In its own window**) and every site you’re signed in to there.
Press **Share browser** to agree. DorkOS may also ask you to confirm it’s you.
Sign-ins from the **In DorkOS** view inside the desktop app are never shared.

- **Stop sharing** works at any time. The agent loses access before its next step.
- If the agent is in the middle of a turn that read text from outside your team, like a web page or
  someone else’s message, sharing waits until that turn ends.
- A chat that someone outside your team started can never use your browser.
- Nothing an agent or a web page says can open the sharing question. Only your click in the panel can.

## One chat at a time

One chat uses a browser at a time. If another chat has it, the panel says **This browser is open in another chat**.
It names that chat and links to it when the chat has a title.
Choose **Take it here** to move the browser to the chat you're in.
If that chat's agent is working in the browser right now, the button reads **Take it from** and the agent's name.
Taking it stops what that agent is doing there.
In a room, the panel asks you to open a direct chat with an agent instead.

If an agent in another chat is waiting for you to finish signing in, the panel says so and offers **Open that chat**.

## Pause, close, and reconnect

**Pause agent** stops new browser actions. You can still use the page.
An action already started may finish; pausing does not undo it.

If you navigate or the page changes, the agent must read it again before acting.
An uncertain action is never repeated automatically. Check what happened before continuing.

Closing the panel hides the page. **Close browser**, in the browser’s **⋯** menu, closes the browser DorkOS opened.
Its saved sign-ins are kept. The same menu lists the open tabs and lets you forget saved sign-ins.
If an agent is waiting on you in the browser, closing it also ends that task.
If the browser closes, choose **Reconnect** to open it again.

## DorkOS Cloud stays yours

Agents can't open DorkOS Cloud or dorkos.ai in a browser DorkOS gives them.
You can still open them yourself in your own browser.
Your agent can't read or act on a page from either site.
If it tries, or a link takes it there, it pauses. Choose **Resume agent** once you have moved on.

Saved sign-ins for older browser tools never keep a DorkOS sign-in.
DorkOS removes one saved by an earlier version the next time it starts.
A browser tool DorkOS can't keep off these sites is left out of the chat.

## What DorkOS installs

DorkOS includes the Playwright library. You do not install Playwright separately.
If Google Chrome is installed, **In its own window** uses it. If not, it downloads the matching Chromium browser on first use.
The library and browser are separate downloads, and DorkOS keeps their versions paired.

The desktop view uses Electron’s built-in browser instead.
Some websites restrict sign-ins from embedded browsers. Use **In its own window** for those sites.

This release pins Playwright to 1.65.0-alpha-2026-10-30. That is a pre-release (test) build of Playwright, not a stable one.
The Chromium it downloads is version 157.
Local browser behavior has been verified on macOS. Windows desktop remains an early alpha;
Windows and Linux local-browser behavior still require platform verification.
These choices are for DorkOS running on your computer.

## Previously configured browser tools

Existing custom browser servers and saved sign-ins are kept.
The older **signed-in browser** uses Playwright MCP and a separate hidden page.
It does not share the live page you view in the Agent browser.
Use the **Agent browser** for live pages. Existing custom tools remain in **Toolkit**.
The older `dorkos browser login`, `status` and `forget` commands still manage their saved sign-ins.
Those saved files are separate from the Agent browser’s choices.
The Mac app adds the `dorkos` command only when you ask: choose **Install** in **Settings › This computer › Terminal command**. Without it, use **Open sign-in window** on the card instead.
