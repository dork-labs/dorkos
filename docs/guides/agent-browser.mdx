---
title: Browser
description: Share a live browser page with the agent in your current chat.
---

Open **Browser** from the right panel’s **+** menu. Choose where the page opens.
Your agent uses that same live page. You can click, type, and navigate while it works.

## Choose a browser

**DorkOS browser** opens the page inside the desktop app’s right panel.
It is the desktop default. Its saved sign-ins are separate from your usual browser.
Chrome extensions do not run inside this view. It stays in the right panel;
it cannot pop out into a floating view.

Some sites open an extra sign-in window. These windows are for you;
your agent stays on the original page. Finish signing in, then close the extra window.

**New browser window** opens a visible Chromium window with separate saved sign-ins.
DorkOS keeps those sign-ins when you close and reopen it. Your usual tabs stay separate.
This is the default when you use the local npm-installed web app.

**Your existing browser** uses a tab you choose in your running Chrome or Edge.
It keeps your usual sign-ins and extensions. DorkOS does not copy your browser’s saved data.

The npm web app cannot put an arbitrary browser inside its page.
Choose either window option, or use the desktop app for **DorkOS browser**.

## Allow your existing browser

1. Choose **Your existing browser**, then **Chrome** or **Edge**.
2. Copy the address shown and open it in that browser.
3. Turn on **Allow remote debugging for this browser instance**.
   This is the browser’s own label for allowing a tool to use its pages.
4. Allow the connection when your browser asks.
5. Choose the tab your agent should use.

Only the selected tab is shared with the agent in your current direct chat.
Changing tabs clears its previous view of the page. A browser opened from Rooms stays human-only.

Chrome or Edge must already be running. This release checks browser versions 144 through 155.
For an older browser, update it. For a newer browser, update DorkOS before connecting.
If the setting is unavailable, use **New browser window**.

## Pause, close, and reconnect

**Pause agent** stops new browser actions. You can still use the page.
An action already started may finish; pausing does not undo it.

If you navigate or the page changes, the agent must read it again before acting.
An uncertain action is never repeated automatically. Check what happened before continuing.

Closing the panel hides the page. **Disconnect** ends sharing.
Disconnecting your existing browser leaves its tabs and sign-ins intact.
If the browser closes, choose **Reconnect**, then choose its tab again.

## What DorkOS installs

DorkOS includes the Playwright library. You do not install Playwright separately.
**New browser window** downloads the matching Chromium browser on first use.
The library and browser are separate downloads, and DorkOS keeps their versions paired.

The desktop view uses Electron’s built-in browser instead.
Some websites restrict sign-ins from embedded browsers. Use **Your existing browser** for those sites.

This release pins Playwright to 1.63.0 and its managed Chromium to version 153.
Native desktop browsing is a macOS proof target. Windows desktop remains an early alpha;
Windows and Linux local-browser behavior still require platform verification.
These choices are for DorkOS running on your computer.

## Previously configured browser tools

Existing custom browser servers and saved sign-ins are kept.
The former saved-browser setup created a separate hidden page; it did not share the page you viewed.
Use **Browser** for the three live-page choices above. Existing custom tools remain in **Toolkit**.
The older `dorkos browser status` and `forget` commands still manage their saved sign-ins.
Those saved files are separate from the new Browser choices.
